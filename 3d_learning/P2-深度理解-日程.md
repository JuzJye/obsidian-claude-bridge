# P2 · 深度理解执行日程（W2-W5）

[返回3D Learning](_index.md) ｜ [唯一主计划](3D感知与机器人学习计划.md)

**本页按主计划的原周主题与任务预算展开**：W2几何/深度/标定，W3检测与6D位姿，W4重建/神经渲染，W5视觉触觉/VLM/操作感知。每周原20h保留，加约10h学习VLA、世界模型和操作算法；Learning只作扫盲支撑。

每日顺序固定为**宏观定位 → 原理与算例 → 原/新增实验 → 总结与次日衔接**；宏观和总结计入下列时段，不另加小时。D1-D5原2.5h+新增1.5h，D6原5h+新增1h，D7原2.5h+新增1.5h。原教材/论文任务见主计划；题名/链接先看文末核验提示。

每个“输出”是当天的验收目标，不表示已完成。每天记录环境/版本、结果、未理解问题。新增模型以图解和最小实验推进，原模块实现与论文精读仍按原计划完成。

## W2 · 3D几何、立体视觉与标定

**原20h分配**：3D变换与几何6h；立体视觉与深度估计7h；相机标定4h；论文精读3h。 **新增10h**另列，不挪用原预算。

### D1 · 投影与坐标

- [ ] **原任务（2.5h）**：齐次坐标、相机投影矩阵与坐标变换；实现点投影/反投影。
- [ ] **新增（1.5h）**：操作：base/ee/camera/TCP与关节/末端动作空间；Learning：输入、参数、目标与单位。
- [ ] **输出与总结**：坐标链图和一个单位错误反例。

### D2 · 对极几何与三角化

- [ ] **原任务（2.5h）**：对极约束、E/F、三角化的几何解释与推导。
- [ ] **新增（1.5h）**：操作：二维二连杆FK/IK，数值IK的误差迭代；把感知目标与机器人关节目标分开。
- [ ] **输出与总结**：手算二连杆位置，图示多解/不可达。

### D3 · PnP与立体匹配

- [ ] **原任务（2.5h）**：PnP/几何变换收尾1h；匹配、视差到深度1.5h。
- [ ] **新增（1.5h）**：操作：雅可比、阻尼最小二乘和奇异位形；看局部线性近似的边界。
- [ ] **输出与总结**：PnP输入输出卡、雅可比的一个数值例。

### D4 · 深度获取算法

- [ ] **原任务（2.5h）**：传统与学习式立体匹配；对比代价与视差误差传播。
- [ ] **新增（1.5h）**：Learning：loss/metric、梯度更新、batch/epoch、划分与泄漏；用同一感知问题解释。
- [ ] **输出与总结**：立体匹配比较表，训练与测试数据边界。

### D5 · 相机标定

- [ ] **原任务（2.5h）**：内/外参、畸变、非线性优化；OpenCV标定实验与参数含义。
- [ ] **新增（1.5h）**：操作：感知误差到末端误差，视觉反馈纠偏；标定不能被动作归一化替代。
- [ ] **输出与总结**：重投影/工作空间误差分析图。

### D6 · 论文与标定实验

- [ ] **原任务（5h）**：立体/深度论文与实验3h；标定实验1.5h；GCNet等精读0.5h。
- [ ] **新增（1h）**：VLA动作单位/坐标接口30min；状态转移中的动作和采样周期30min。
- [ ] **输出与总结**：numpy几何模块、深度方法对比、动作接口初稿。

### D7 · 精读与闭卷总结

- [ ] **原任务（2.5h）**：完成原论文精读与前沿部分；回查几何、立体、标定输出。
- [ ] **新增（1.5h）**：归纳运动学与学习五格卡；预训练/微调只扫盲；口述原几何如何约束VLA和预测器。
- [ ] **输出与总结**：三句话、未理解问题，衔接W3检测与物体/夹爪位姿。

**周验收**：几何推导与numpy实现、立体方法比较、标定影响分析、原3h论文精读均完成；新增二连杆/雅可比例与动作接口卡。

## W3 · 3D检测与6D位姿估计

**原20h分配**：3D检测8h；2D到3D投影4h；6D位姿5h；系统应用分析3h。 **新增10h**另列，不挪用原预算。

### D1 · PointNet

- [ ] **原任务（2.5h）**：PointNet点集表示、对称聚合、分类/分割；手写核心模块。
- [ ] **新增（1.5h）**：Learning/VLA：表征、token、embedding，分类不变与逐点分割等变；输入形状图。
- [ ] **输出与总结**：PointNet模块及点重排实验。

### D2 · PointNet++与Frustum PointNet

- [ ] **原任务（2.5h）**：多尺度、局部邻域、2D-3D联合检测；对照原论文。
- [ ] **新增（1.5h）**：操作：物体位姿到夹爪位姿；平行夹爪宽度、接近方向、抓取候选质量。
- [ ] **输出与总结**：一张抓取候选图，区别检测分数与抓取成功。

### D3 · 检测实现与评价

- [ ] **原任务（2.5h）**：补全检测模块、指标匹配与误差分析，核对具体数据集协议。
- [ ] **新增（1.5h）**：操作：配置空间、RRT/RRT-Connect直觉与路径搜索；一条二维避障例。
- [ ] **输出与总结**：检测系统局部图、规划路径与失败例。

### D4 · 2D到3D投影

- [ ] **原任务（2.5h）**：投影、BEV、伪雷达、多模态融合；原CenterNet相关材料按任务用途阅读。
- [ ] **新增（1.5h）**：操作：IK可达性、自碰撞/环境碰撞、路径和时间参数化区别。
- [ ] **输出与总结**：目标位姿→可达性→无碰撞路径→轨迹的图。

### D5 · 6D位姿

- [ ] **原任务（2.5h）**：NOCS等原任务、旋转表示、RANSAC/ICP与对称性；核对物体参考系。
- [ ] **新增（1.5h）**：操作/VLA：末端绝对/增量、base/ee动作方向；BC监督动作的坐标与表示。
- [ ] **输出与总结**：旋转表示对照、动作回放检查。

### D6 · 综合原理与小实验

- [ ] **原任务（5h）**：检测收尾0.5h；投影1.5h；位姿2.5h；实际系统分析0.5h。
- [ ] **新增（1h）**：ACT/Diffusion Policy动作chunk和多模态动作分布的图解。
- [ ] **输出与总结**：可运行PointNet模块、投影笔记、旋转对比和系统图。

### D7 · 系统分析与总结

- [ ] **原任务（2.5h）**：完成实际3D检测/位姿系统分析；按模块说明输入输出与误差。
- [ ] **新增（1.5h）**：用抓取筛选算例检索新增知识，Learning对比/生成学习五格卡。
- [ ] **输出与总结**：W3完整原产出；疑问归入W4重建或W5操作感知。

**周验收**：保留原8/4/5/3h四组任务与6D位姿所在周；新增抓取筛选、规划/可达性图、VLA表征与动作生成初识。

## W4 · 3D重建与神经渲染

**原20h分配**：SfM5h；NeRF与隐函数7h；几何感知重建5h；2D/3D统一视角3h。 **新增10h**另列，不挪用原预算。

### D1 · SfM管线

- [ ] **原任务（2.5h）**：特征、匹配、增量/全局SfM与相机关系；梳理完整管线。
- [ ] **新增（1.5h）**：世界模型：静态几何、渲染视角与操作动作条件；画静态/动态差异。
- [ ] **输出与总结**：SfM图与未来预测问题定义。

### D2 · Bundle Adjustment

- [ ] **原任务（2.5h）**：BA、重投影优化、原SfM论文精读；整合前周几何。
- [ ] **新增（1.5h）**：世界模型：状态/观测、部分可观测、历史、潜状态与速度信息。
- [ ] **输出与总结**：观测→历史表征→状态预测图。

### D3 · NeRF与体渲染

- [ ] **原任务（2.5h）**：体积渲染、隐函数与显函数，推导核心关系与几何直觉。
- [ ] **新增（1.5h）**：世界模型：转移样本(s,a,s')、一步预测损失；拟合简单位置/速度模型。
- [ ] **输出与总结**：一个小动态预测器和数据假设。

### D4 · 加速与3DGS

- [ ] **原任务（2.5h）**：Instant-NGP、3DGS的表示/渲染差异；原NeRF实验继续。
- [ ] **新增（1.5h）**：世界模型：teacher forcing与自由rollout，1/5/10步误差、分布外动作。
- [ ] **输出与总结**：预测/真实轨迹和误差图。

### D5 · 几何约束与重建

- [ ] **原任务（2.5h）**：保留几何感知重建任务；按主计划资料勘误选择可核实来源。
- [ ] **新增（1.5h）**：世界模型与操作：MPC候选评分、碰撞几何；与Dreamer式想象训练区分。
- [ ] **输出与总结**：规划/想象训练两条图，模型误差反例。

### D6 · 重建实验与统一表示

- [ ] **原任务（5h）**：NeRF实验2h；几何约束重建2.5h；2D/3D特征融合0.5h。
- [ ] **新增（1h）**：V-JEPA 2/2-AC无动作预训练与动作条件阶段图解；不新增大模型训练。
- [ ] **输出与总结**：原NeRF实验记录、小模型多步对照。

### D7 · 统一视角与总结

- [ ] **原任务（2.5h）**：完成2D→3D特征学习总结、重建/SfM/NeRF产出回查。
- [ ] **新增（1.5h）**：检索世界模型与Learning概念；解释图像重建好不代表接触预测准。
- [ ] **输出与总结**：神经场推导、世界模型边界；衔接W5视觉触觉操作。

**周验收**：保留SfM/NeRF/几何约束/特征融合任务；新增小型动作条件模型和规划用途验证，不能拿世界模型替换原重建实验。

## W5 · 机器人视觉伺服、触觉、VLM与操作感知

**原20h分配**：视觉伺服与接触感知6h；VLM/Embodied AI6h；操作感知5h；论文综述3h。 **新增10h**另列，不挪用原预算。

### D1 · 视觉触觉基础

- [ ] **原任务（2.5h）**：原视觉伺服、触觉表示与多模态融合材料；说明输入信号。
- [ ] **新增（1.5h）**：操作：自由运动/接触、位置/力/阻抗/导纳控制；弹簧阻尼直觉与单位。
- [ ] **输出与总结**：接触控制框图与一个算例。

### D2 · 多模态接触感知

- [ ] **原任务（2.5h）**：视觉与触觉编码、融合，保留原接触感知学习内容。
- [ ] **新增（1.5h）**：操作：PBVS/IBVS与闭环误差；从接触/滑移信号到纠偏或重抓条件。
- [ ] **输出与总结**：感知与控制分工，失效边界。

### D3 · 视觉触觉收尾与VLM

- [ ] **原任务（2.5h）**：视觉触觉1h；VLM、语言与3D感知关系1.5h。
- [ ] **新增（1.5h）**：VLA：RT-2/OpenVLA原版结构，语言视觉到动作token，反归一化。
- [ ] **输出与总结**：多模态感知设计、VLA输入输出卡。

### D4 · VLM与Embodied AI

- [ ] **原任务（2.5h）**：原语言引导3D感知与规划概念；区分目标定位和低层动作。
- [ ] **新增（1.5h）**：VLA/操作：π0、flow matching；BC/DAgger、ACT/Diffusion Policy和分布偏移。
- [ ] **输出与总结**：模块化/层级/VLA比较图，动作均值失败例。

### D5 · 机器人操作感知

- [ ] **原任务（2.5h）**：原检测→操作系统设计，跟踪参考坐标和任务对象。
- [ ] **新增（1.5h）**：世界模型：多模态接触预测的条件；Learning：RL/IL、on/off-policy、offline/online。
- [ ] **输出与总结**：原操作感知系统图与学习五格卡。

### D6 · 综合原文与接口验证

- [ ] **原任务（5h）**：VLM/Embodied AI2h；操作感知2.5h；综述0.5h。
- [ ] **新增（1h）**：查一个VLA官方demo的观测/动作与资源条件；LoRA/冻结适配只看更新参数范围。
- [ ] **输出与总结**：P3项目Π-1需求清单，后续VLA实现条件。

### D7 · P2综述与收敛

- [ ] **原任务（2.5h）**：原论文综述、推导、3个手写模块与20篇精读记录验收。
- [ ] **新增（1.5h）**：三块统一口试；多任务/元学习/持续学习扫盲；列入P3待验证问题。
- [ ] **输出与总结**：理论地图、操作算法导航、下一周数据与基线第一步。

**周验收**：保留原多模态与操作感知路线及原P2验收：核心推导、3个手写模块、20篇精读；新增三块只增加验收，不降低原标准。

## P2结束时如何检查

- [ ] 原计划四组推导与3个手写核心模块完成，可解释公式假设与失败边界。
- [ ] 原计划20篇精读及比较表完成；错误资料链接不能计作已阅读相关论文。
- [ ] 新增VLA结构/动作接口图、小世界模型与多步误差、操作算法链和Learning五格卡完成。
- [ ] P3项目Π-1仍从基础3D检测/位姿的数据与基线开始；未完成项记录差额，不以新增主题抵扣。
- [ ] 所有完成状态来自真实学习记录；没有训练的模型不写“已验证”。
