# P3 · 原项目上的增量实战（W6-W17）

[返回3D Learning](_index.md) ｜ [唯一主计划](3D感知与机器人学习计划.md)

**项目与周次以主计划原文为准**：Π-1基础感知 → Π-2视觉/触觉/语言 → Π-3RL仿真操作 → Π-4 A自驾或B多臂（原推荐B）。本页只把原任务落实为周任务池，并加入VLA、世界模型与操作算法。

每周原20h+新增10h，30h是参考预算。工作日各4h，D6为6h，D7为4h；原/新增工作交叉安排但分别记账，复用相同数据、仿真器和评价脚本。同一个实验若服务多个板块，只计一次时间。

## 每天怎样执行

- D1-D2：先画当天模块在系统中的位置，再做数据/基线/算法推进，结尾记录结果和未理解问题。
- D3：继续推进并做一次误差/数据/接口检查；用数值例解释问题。
- D4-D5：改进、对照与调试；原任务保留，新增模型数量按可用时间调整。
- D6：大块训练/实验与可视化，区分主动学习时间与后台等待时间。
- D7：收尾与闭卷解释，固定1h周复盘，写下一周第一步。每天均遵循宏观→微观→总结。

## Π-1 · W6-W8 · 基础3D感知系统

端到端3D检测与6D位姿，从RGB-D到可操作姿态。保留原YCB-Video/LineMOD、方法候选、评估与输出；模型实现条件先核对，不因新增块直接换掉原任务。

### W6 · 数据与基线（原20h + 新增10h）

**原任务保持**：

- [ ] 数据加载管道与标准化评估指标。
- [ ] 复现原计划候选中的一个6D位姿方法，核对数据与物体/类别级设置。
- [ ] 交可复用数据加载器与评估框架。

**新增三块任务池**：操作坐标/单位/时间戳和动作接口4h；世界模型转移字段2h；VLA观测/动作接口初识2h；图解总结2h。

**新增输出/检查**：观测/动作契约；GT投影与动作方向检查。

### W7 · 模型改进（原20h + 新增10h）

**原任务保持**：

- [ ] 保留多尺度特征、损失或几何约束的改进方向。
- [ ] 实验原计划的3—5个方案，记录性能比较与失败归因。
- [ ] 交改进模型与实验报告。

**新增三块任务池**：抓取候选生成与质量4h；IK可达性/碰撞筛选4h；感知误差影响总结2h。

**新增输出/检查**：原感知消融之外，增加位姿误差→抓取/规划可行性的分析。

### W8 · 应用与可视化（原20h + 新增10h）

**原任务保持**：

- [ ] 集成相机标定→检测→位姿→可视化的原完整管道。
- [ ] 真实RGB-D设备或高质量仿真测试。
- [ ] 交原推理管道与可视化工具。

**新增三块任务池**：位姿→抓取→IK/轨迹5h；动作执行/回放与接触记录3h；原/新增结果总结2h。

**新增输出/检查**：最小操作算法链与动作日志，为原Π-2提供接口。

**原项目交付保持**：代码项目`robot_pose_estimation/`、原性能/融合/学习曲线分析、系统文档与演示；新增证据作为同项目的实验与报告章节。

## Π-2 · W9-W11 · 多模态机器人感知系统

集成视觉、触觉、语言，保留原视觉/触觉特征、对齐、多模态融合和语言查询三周任务。新增预测/动作接口复用其数据，不把此项目改成纯策略训练。

### W9 · 触觉感知模块（原20h + 新增10h）

**原任务保持**：

- [ ] 学习原触觉编码材料与开源数据。
- [ ] 构建触觉特征提取器。
- [ ] 建立视觉-触觉对齐（对比或多任务学习），交编码器与对齐模型。

**新增三块任务池**：接触状态与控制直觉2h；带动作的触觉/状态转移小模型4h；VLA数据字段2h；总结2h。

**新增输出/检查**：先查数据是否含同步动作；无动作数据只可做观察预测，动作条件例另用小型合成转移。

### W10 · 多模态融合（原20h + 新增10h）

**原任务保持**：

- [ ] 保留原Transformer或其他融合架构设计。
- [ ] 联合编码器与交叉注意机制实现。
- [ ] 在原6D位姿/接触预测等任务评估，交融合模块与比较。

**新增三块任务池**：多模态动作条件预测与1/5/10步误差5h；有无触觉/深度的预测对照3h；图解总结2h。

**新增输出/检查**：多模态融合原评价与动态预测评价分别报告，不能只看训练loss。

### W11 · 语言引导与端到端系统（原20h + 新增10h）

**原任务保持**：

- [ ] 集成原CLIP/VLM语言查询。
- [ ] 实现描述物体→检测→位姿估计的原端到端管道。
- [ ] 测试自然语言指令，交原语言感知系统和Demo。

**新增三块任务池**：VLA官方demo及接口核对4h；语言目标→操作算法的模块化路线3h；执行数据适配/回放2h；总结1h。

**新增输出/检查**：已有语言感知与VLA的差异卡；可运行demo；下周仿真动作接口。

**原项目交付保持**：代码项目`multimodal_robot_perception/`、原性能/融合/学习曲线分析、系统文档与演示；新增证据作为同项目的实验与报告章节。

## Π-3 · W12-W14 · 强化学习与仿真操作系统

保留基于3D感知反馈的操作任务、MuJoCo/PyBullet候选、PPO/SAC原RL基线及Sim-to-Real分析。IL/VLA/世界模型作为新增对照，不替代原RL训练。

### W12 · 仿真环境与感知集成（原20h + 新增10h）

**原任务保持**：

- [ ] 搭原计划1—2个标准操作任务，如pick/push。
- [ ] 集成相机模拟，获取RGB-D观测。
- [ ] 接入Π-1检测并验证，交仿真、感知接口与数据记录工具。

**新增三块任务池**：演示/脚本采数与BC基线4h；同环境转移预测器3h；VLA动作适配2h；总结1h。

**新增输出/检查**：统一obs/action/reward/reset；BC/模型使用的数据与原RL交互分别计数。

### W13 · RL训练（原20h + 新增10h）

**原任务保持**：

- [ ] 保留基于位姿、接触、任务成功的奖励设计。
- [ ] 训练原PPO/SAC路线的RL agent。
- [ ] 完成原有/无感知反馈对照，交RL policy与曲线。

**新增三块任务池**：在BC基础上选ACT/Diffusion Policy或一个可用VLA作对照4h；用世界模型评分候选或规划4h；汇总2h。

**新增输出/检查**：固定观测、动作接口、测试初态和试验预算，区分数据/算力差异与方法差异。

### W14 · Sim-to-Real与可迁移性（原20h + 新增10h）

**原任务保持**：

- [ ] 分析原仿真-真实domain gap。
- [ ] 设计原域随机化等适应策略。
- [ ] 可行时保留原真机快速适应验证，交迁移方案与报告。

**新增三块任务池**：VLA/IL小范围适配或控制参数对照4h；世界模型域偏移与恢复实验4h；总结2h。

**新增输出/检查**：迁移前后成功数/总数、预测残差、延迟与失败例；无真机时明确实验证据边界。

**原项目交付保持**：代码项目`robot_rl_simulation/`、原性能/融合/学习曲线分析、系统文档与演示；新增证据作为同项目的实验与报告章节。

## Π-4 · W15-W17 · 原两个方向择一

**保留原选项**：A自动驾驶3D检测与追踪；B多臂协作感知（原推荐）。没有另外引入“Sim-to-Real/系统深化/自驾”三个分支；Sim-to-Real仍位于原Π-3的W14。

| 周 | 原任务保持（20h） | 新增三块（10h） | 验收 |
| --- | --- | --- | --- |
| W15 | 多视角融合理论、每臂相机的分布式架构、坐标统一与信息融合 | 双臂动作/时间同步3h；双臂VLA接口与语言分工2h；联合状态/动作预测3h；总结2h | 原多视角对齐模块，外加联合动作契约与预测图 |
| W16 | 基于Π-3扩展原2—3臂协作、臂间通信/任务分配、协作RL训练 | 一个交接子任务的规划/控制/冲突处理4h；模型预测与恢复3h；语言/策略对照1h；总结2h | 原协作RL环境与policy，外加交接/恢复的受控对照 |

## 全局验收与执行约束

- [ ] 原四个项目的任务/产出按主计划完成，每个项目有独立代码目录与可复现文档。
- [ ] 原数据基准、三篇系统文档/三个演示等要求保留；每项目至少留一份实际文档，按主计划的计数提示整理。
- [ ] 新增VLA推理/接口/受控对照、小世界模型/多步误差/评分或恢复、完整操作算法链。
- [ ] 在同一个项目报告中区分原任务结果与新增实验，记录模型版本、训练数据、观测、动作单位、坐标、时间戳与硬件。
- [ ] 成功数/尝试数、数据和交互预算、测试初态、随机种子及耗时清楚；不同输入和数据量的差异不能直接归因于模型结构。
- [ ] 小型实验以解释原理和验证假设为目标；大VLA适配先确认官方实现的硬件/机器人条件，不从零训练大模型。
- [ ] 原任务超预算时记录实际差额，不自动换项目或删原任务。新增部分优先减少重复模型/实验，保留三块最小产出。
- [ ] 代码项目在vault外维护；笔记库只保存计划、学习记录和有效链接，不初始化Git。
