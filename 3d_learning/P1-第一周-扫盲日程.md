# P1 · 第一周扫盲（27h）

[返回 3D Learning](_index.md)

> 本周目标：建立“感知 → 表示 → 策略 → 预测 → 反馈”地图，能用小算例解释关键概念。
> D1、D2 保留原安排；D3 起增密。每天依照[主计划](3D感知与机器人学习计划.md)先宏观、再微观、最后总结。公式先弄懂符号与单位，复杂推导留到 P2。

## 原计划覆盖检查与新增三块

本页落实[唯一主计划](3D感知与机器人学习计划.md)的第一周原20h任务，加约7h新增内容。D1/D2个人记录保持；已有内容按实际完成记录抵扣，不要求重学。以下原条目仍须覆盖，不能因新增内容略过数学、框架或工具。

| 原任务组 | 原条目 | 在每日材料中的归位 |
| --- | --- | --- |
| 3D基础6h | 概论、表示、传感器、经典任务各1.5h | D1概论/表示，D2传感器，D3任务 |
| 机器人7h | RL1.5h、感知1.5h、控制1h、仿真/VLM1.5h、导航1h；余0.5h整理 | D4学习与仿真，D5感知/控制/导航，D6-VLM；D7收敛 |
| 遥操与自驾2h | 遥操1h、自驾感知1h | D5遥操、D6-BEV，自测回查不足项 |
| 理论基础5h | 数学2h、DL框架1.5h、论文工具1.5h | D1-D3公式/坐标与D7数学回查；D6框架；D6-D7论文工具 |

**覆盖表与下文日程是同一周内容的两种视角，不额外叠加20h**。原任务组的分钟数可跨日调整；若实际超时，增加当天学习时长并记录，不能以“扫过名词”替代完成。

新增三个板块在本周的定位：

- VLA：D3建立输入输出，D6看结构与动作接口。
- 世界模型：D3小动态算例，D4动作条件转移，D6规划/想象训练。
- 操作算法：D3物体位姿/抓取位姿，D4模仿/RL策略，D5运动学/规划/控制，D7闭环自测。
- Learning扫盲嵌在三块中，原RL/控制已经学过的概念只复述，不重复算新增课时。

## D1 · 3D表示与坐标系（2.5h）

**输入 (1.5h)**
- [ ] 五种3D表示的适用边界，各写2句话（0.6h）
  - 点云 / 体素 / 网格 / 深度图-RGBD / 隐式场（SDF、NeRF）
  - 关注：谁是稀疏的、谁能微分、谁能直接送进CNN
- [ ] 坐标系链条梳理（0.5h）
  - 世界 → 机器人base → 相机 → 图像像素，画出完整变换链
- [ ] 位姿表示速查（0.4h）
  - 旋转矩阵 / 欧拉角 / 四元数 / 轴角 / 6D连续表示
  - 只记结论：为什么深度学习回归旋转不用欧拉角

**动手 (0.6h)**
- [ ] `pip install open3d trimesh`，用 Open3D 打开任意一个点云，转个视角（0.6h）

**产出 (0.4h)**
- [ ] 笔记 `3D表示对比表.md`：表示 / 稠密性 / 可微 / 典型任务 / 典型模型

**核心问题（写答案，不查也要猜一个）**
- 为什么2D CV的卷积不能直接用在点云上？

## D2 · 传感器与深度获取（2.5h）

**输入 (1.8h)**
- [ ] 深度获取四条路线的原理与失效场景（1h）
  - 双目立体（纹理缺失就废）
  - 结构光 / ToF（RealSense D4xx vs L515，室外阳光下的差异）
  - LiDAR（机械式 vs 固态，线数与点云稀疏度）
  - 单目深度估计（尺度歧义问题）
- [ ] 相机模型（0.5h）
  - 针孔模型、内参K的物理含义、径向畸变
- [ ] 标定在干什么（0.3h）
  - 内参标定 / 手眼标定（eye-in-hand vs eye-to-hand）——机器人操作的第一道坎

**动手 (0.4h)**
- [ ] 用 OpenCV 棋盘格标定示例跑一遍，看清 K 和 dist 输出

**产出 (0.3h)**
- [ ] 笔记 `传感器选型决策表.md`：场景 → 推荐方案 → 已知坑

**核心问题**
- 机械臂抓取要 mm 级精度，你会选哪个传感器？手眼标定误差会怎么传导到抓取失败？

## D4 · 从数据到策略：IL、RL与仿真（4h）

**宏观（20min）**
- [ ] 画“数据来源 → 学习目标 → 策略 → 环境反馈”；回忆 D3 的策略与动态模型方向。

**微观（100min）**
- [ ] BC（25min）：演示中的动作就是监督标签；同一观测可有多个合理动作；复习动作均值失败例。
- [ ] DAgger（20min）：策略偏离专家轨迹后，到自己访问的状态请专家纠正；区别于只收更多相同演示。
- [ ] RL（35min）：状态/观测、动作、奖励、回报、策略、V/Q；用三步抓取算折扣回报。
- [ ] 三组正交概念（20min）：on/off-policy、online/offline、model-based/model-free。PPO、SAC只定位，不推更新式。

**连接与动手（80min）**
- [ ] Diffusion Policy 与 ACT（25min）：输出动作序列，演示训练；生成式动作头不等于强化学习。
- [ ] 仿真器与数据（20min）：MuJoCo、Isaac Lab、ManiSkill、RLBench 分别提供什么；动力学、外观、传感器噪声的差异。
- [ ] 动手（35min）：小环境列出 obs/action/reward/reset；画真实一步转移和模型预测一步转移，不要求今天训练大策略。

**总结（40min）**
- [ ] 写“有演示、无演示、有可靠仿真”三种条件下如何选择 BC / IL / RL。
- [ ] 核心题：离线演示上的动作误差小，为什么闭环仍失败？世界模型能帮助什么，又可能增加什么错误？
- [ ] 输出策略范式对照与未理解问题，衔接 D5 的控制接口。

## D5 · 控制、导航、遥操与动作落地（4h）

**宏观（20min）**
- [ ] 画“任务层 → 策略层 → 轨迹/控制层 → 执行器 → 观测反馈”，标出各层输入输出。

**微观（110min）**
- [ ] 控制（45min）：正/逆运动学、雅可比、奇异点；位置/力/阻抗控制；RRT、MoveIt 的职责。
- [ ] 导航（35min）：里程计、后端优化、回环；地图、占据、代价、规划；相机轨迹不等于物体位姿。
- [ ] 遥操（30min）：ALOHA、GELLO、VR 的映射；时间同步、延迟、失误演示，哪些字段必须随动作记录。

**连接与动手（70min）**
- [ ] 动作接口卡（30min）：关节/末端，绝对/增量，base/ee，相位/时间戳，m/mm，夹爪编码，归一化。
- [ ] 算例（20min）：坐标系转 90°，同一个三维增量为什么造成不同运动？chunk长短如何影响反馈？
- [ ] 失败定位（20min）：5mm 偏差出现在感知、标定还是控制？阻抗控制的纠偏有接触几何与参数边界，不能保证救回。

**总结（40min）**
- [ ] 交动作接口卡和控制导航概念表；合上资料口述完整执行链。
- [ ] 核心题：VLA输出数值为什么还不能直接发给任何机械臂？衔接 D6 的模型比较。

## D6 · VLA、世界模型与环境准备（6h）

**宏观（20min）**
- [ ] 默画 VLM / VLA / 世界模型的输入输出，比较推理时谁选择动作。

**微观：VLA（75min）**
- [ ] CLIP、视觉编码器、语言token、本体状态、动作头各做什么（20min）。
- [ ] RT-2 → OpenVLA原版 → π0 三张结构图（35min）：离散动作token、连续动作chunk、flow matching；读原文架构图和数据段。
- [ ] 开放词汇感知（20min）：Grounded-SAM / DINOv2 / 3D特征提升；有语言的模块化系统与VLA的区别。

**微观：World Model（60min）**
- [ ] 编码器 → 隐状态 → 动作条件转移 → 未来；图区别“重建观测”与“预测后果”（20min）。
- [ ] DreamerV3（20min）：学模型、在想象中改进策略、回环境采数据；不是每一步都用MPC。
- [ ] V-JEPA 2 / 2-AC（20min）：无动作视频预训练与动作条件训练分开看；预测特征不一定生成像素。

**拓宽：BEV与多模态（45min）**
- [ ] BEV与LSS/BEVFormer（20min），多传感器早/中/晚融合（15min），触觉信号及作用（10min）。
- [ ] 核心区别：静态占据回答哪里被占用，动态预测回答行动后怎样变化。

**动手：环境（120min）**
- [ ] 先核对本机或远端可用算力、Python/PyTorch（30min）；CUDA只在兼容NVIDIA环境验证。
- [ ] 单独建学习环境，按实际实验安装 Open3D / OpenCV；PyTorch3D / MMDet3D 延后到用时安装（30min）。
- [ ] MuJoCo或课程选定仿真器运行一场景，保存环境信息与运行证据（40min）。
- [ ] 整理来源链接和阅读记录（20min）。大VLA今天只读结构，硬件适配留 P3。

**总结（40min）**
- [ ] 输出三张模型卡：输入/输出/数据/目标/推理/失败边界；记录环境已验证项和待确认项。
- [ ] 次日用这些卡合成全局图。

## D7 · 收敛、检索与P2选题（4h）

- [ ] 宏观（20min）：闭卷画感知、VLA、World Model、Learning的关系，再对照修正。
- [ ] 微观回查（60min）：从 D1-D6 各选一个错误/疑问，用算例或反例解决；核对原数学2h中的特征值/QR、刚体变换/李群覆盖。
- [ ] 可视化输出（60min）：至少30个概念节点；每条边写关系动词；将原论文工具workflow/资源整理同步记入。
- [ ] 验收（60min）：讲解一条抓取闭环；填写三个模型的学习五格卡；回跑一个实验；核对运行环境。
- [ ] 总结与下周（40min）：兴趣×相关度打分、疑问按W2-W5归位、确认最小实验规模。

**周验收**
- [ ] 区别3D表示、感知任务、模型结构与学习范式。
- [ ] 解释VLA和世界模型的输入输出，给出组合方案及失效反例。
- [ ] 算IoU、解释ADD-S和双向Chamfer；说明离线指标为何不足。
- [ ] 运行一个小实验与仿真demo，有环境与结果记录。
- [ ] 图谱、疑问清单和P2安排相互有链接；未完成项如实保留。
- [ ] 原计划数学、DL框架、论文工具、遥操/自驾和15篇abstract均有记录；原资源误引按主计划核验提示处理。
