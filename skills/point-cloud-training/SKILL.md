# 点云补全训练

把数据、训练链路和实际效果分开验收：训练能跑、合成指标改善、真实业务适配是三个不同结论。支持当前用户指定的计划、执行或复盘范围；加载技能本身不启动GPU任务、扩类或部署。

## 按任务取用资料

- 整理原包、伪参考、partial及划分，或审查数据是否够用：读 [数据准备与评价](references/data-and-evaluation.md)。
- 启动微调、处理梯度/显存/恢复、导出模型：读 [训练与恢复经验](references/training-and-recovery.md)。

## 从当前状态开始

先找已有数据清单、训练配置、原模型、状态与完成回执，区分历史记录和本轮事实。明确任务是已知SKU的新视角适配，还是未知形状泛化；以及更关心外轮廓、尺寸、内腔还是下游碰撞约束。

统计原包、保留帧、对象观测、独立摆放/会话、实物实例和合格配对，不把这些数量互换。大量合成样本或重复真实样本不能增加独立实物数。几对可靠样本可以做链路短测，不足以证明泛化。

已有冻结数据只读使用，修订类别、mask、参考或配对时发布新版本。权重、源码、标定、处理参数和来源哈希一起固定；确认使用的离线模型与常驻服务是否真是同一版本。

## 推进顺序

1. **冻结对照与评价协议。** 严格加载原模型，保存基线预测；先固定划分、指标、checkpoint选择规则和复核门槛，再训练。
2. **验证读取器。** 检查同帧来源、米制坐标及输入/目标关系。训练和推理共用partial可独立计算的归一化；padding在归一化之后，完整目标不提供输入的中心、尺度或姿态。
3. **小批次短测。** 实际完成forward、原损失、backward、优化器更新，检查有限梯度和参数变化。分别验证冻结阶段及解冻后恢复，不能以推理成功代替训练可用。
4. **小规模对照。** 伪参考数据优先做合成基线与合成加真实配对的对照，固定初始化、预算和采样比例。采用已验证模型的原损失起步，将外轮廓等业务指标独立报告。
5. **完成评估与交付。** 仅按预定验证集选择checkpoint，之后统一评价测试集和真实诊断集。完成失败清单、预览、推理权重、恢复回执和哈希校验后再决定扩类。

用户只要求计划或复盘时，交付相应方案或分析，不执行上述训练步骤。执行阶段出现非有限值、恢复错误或来源不一致时，修复本阶段再进入长训练，不用增加步数掩盖问题。

## 关键判断

- SAM 3D外观合理且尺寸校正通过，仍只是生成伪参考；隐藏面和内腔不能写成实测真值。
- 已知SKU跨划分共享参考几何可以支持新视角实验，应明确这种共享；不能声称未知形状或独立实物泛化。
- 小样本下真实监督可能更差：先核对规格、状态、配准与输入分布，再考虑提高真实样本权重或增加训练量。
- 冻结encoder时保留需要训练模式的分支。AdaPoinTr的去噪分支依赖训练模式，不能为冻结encoder把整个模型切成eval；小batch的BatchNorm运行统计另行控制。
- CUDA恢复数值异常时，区分遗漏状态与算子非确定性；先用同一中间checkpoint做连续/恢复对照，再定位forward或梯度。不要直接放宽恢复门槛，也不要将本次确定性补丁无检查地应用到其他模型。
- 可见面距离、射线冲突和覆盖率一起看。点到点与点到mesh、采样点比例与像素比例口径不同，不能直接套用同一阈值。
- 业务优先外轮廓时，把冲突定位到外轮廓、遮挡边界或内腔。复核可揭示评价口径问题，但本轮结果保留原门槛，下一轮用开发数据重新确定协议。

## 交付与结论

报告至少包含：数据来源和合格配对数、独立性限制、固定配置与实际步数、原模型/对照组结果、外轮廓/尺寸指标、真实退化样例、恢复和导出证据、剩余缺口及扩类决定。

分别写明技术检查状态、效果门槛状态和生产适用状态。只完成排队或后台启动时报告运行中；短测、实验或伪监督评价通过，不替代业务验证。大型数据与checkpoint留在获准的执行端，按需回传报告和预览。
