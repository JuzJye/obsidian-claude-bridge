# 数据准备与评价

[返回技能](../SKILL.md)

## 原始资料与来源链

先复用已有可信清单，下载/同步时允许续传，按接收端SHA256及ZIP完整性发布原包。源文件变化时保留状态、重试稳定版本；重复导入保留人工审核。原包共享，各SKU引用，避免按SKU重复复制。

盘点“真正保留”的帧：录制目录存在、batch数量多，不表示输入RGB/双目/深度都保留。记录容量截断、丢帧、缺batch、缺标定及来源格式。算法快照按数据格式解码，不通过任意类反序列化来恢复业务对象。

分别统计文件、保留帧、对象观测、会话/摆放及实物。先做精确去重，再审核静止场景的近重复帧；录制时间不同、跟踪ID不同，不足以证明独立摆放或永久SKU身份。

每个观测至少能定位以下信息，字段名可以适配已有仓库：

| 信息 | 必需含义 |
| --- | --- |
| 对象与分组 | SKU、观测ID、会话/摆放组、物理实例或unknown、规格/形态状态 |
| 源输入 | 原包哈希、条目、时间戳及其时钟域、同帧RGB/左右图/标定 |
| 处理 | mask来源及审核、深度来源、版本/权重/参数、过滤前后点云 |
| 几何 | 单位、坐标系、明确方向的变换、参考版本、生成/实测属性 |
| 状态 | 类别、规格、质量、配对、划分、排除原因及修订依据 |

## 真实partial

1. 审查目标是否为整袋、单件、带附件或其他状态。柔性包装、绕线状态、附件姿态变化时，不强行共用固定完整目标。
2. 保留原像素mask；离线补分割另存模型、提示、mask及叠加审核。检查一张mask是否合并了两个物体，以及同一ID是否换了对象。
3. 优先使用来源清楚的已保存生产partial；需要重建时固定双目模型和生产后处理版本，标为离线重算。SDK深度、FFS和其他来源分开标记。
4. 校验分辨率、同帧关联、K/T约定和有效深度。必要时审查RGB与stereo-left对齐，不能通过偷偷平移mask消除问题。
5. 保存raw、filtered、trusted及keep/reason信息，使过滤结果可回溯到raw；稳定外缘不能仅因靠近mask边界就被裁掉。

本次曾发现奇数尺寸裁剪的相位相关估计器有约半像素自偏置。使用相位相关时可加入同尺寸同图自相关，并保留原始、偏置、校正值及真实平移负例；这不是硬件同步认证，也不是所有图像任务的固定前处理。

## 生成完整伪参考

- 图片用于生成或验证时记录用途。尺寸图是形状与标称尺寸参考，不作为标定图、真实深度或独立精度证据。
- 单图模型先分别生成候选，再用其他视角验证；没有真正多视角融合机制时，不把多张输入说成已融合重建。
- 先确定物体轴，再匹配测量定义。盒类按对应L/W/H；近圆柱优先径向同比例，保留端盘、锥度、凸缘等。标注包含附件时，不能把附件删掉来满足理想圆柱尺寸。
- 确认孔轴或语义轴。近似等长的轴不能只按OBB最短边判断高度。
- 先估计刚体位姿；局部修订限于有图像依据的区域，另存版本。尺寸约束成功不等于完整几何准确。
- 面积采样母本保留分布依据；薄附件可能在8192等小点数导出时丢外缘，可增加在表面上的轮廓极值采样。说明偏置，检查导出跨度与点到mesh距离，不把点数或轴向跨度当完整轮廓精度。

配对状态分开保存“partial有效”“规格身份确认”“可见面匹配”“完整参考状态”。低残差仍可能是错误规格、非唯一位姿或柔性状态不匹配，未通过者保留诊断数据。

## 合成数据与划分

先确定任务和组，再做扰动。组可以是相对视角轨迹、独立摆放、会话或实物，不能把同组相邻帧随机分到训练和验证。

对于已知SKU新视角适配，训练/验证共享同一参考mesh可以是有意设计；报告这种共享。未知形状泛化需要不同几何/实例留出，单纯换相机或随机种子不够。

生成partial时先进行可见性渲染，再施加局部遮挡、孔洞和噪声；随机删完整点云的一部分不等于真实单视角。保存相机、姿态、种子、扰动、来源哈希及完整目标变换。增强噪声只是试验参数，不标为已测真实传感器噪声。

检查干净可见点落在mesh上、目标采样在mesh上、相机重投影和归一化往返。所有扰动保持输入/目标共享的坐标关系；输入噪声与目标几何噪声用途不同。

## 归一化与评价

归一化应匹配模型与部署接口。对于本次AdaPoinTr适配，从有效partial计算中心和尺度，目标应用同一变换；采样/padding顺序与部署一致。完整目标可以用于监督与离线评价，不可参与输入的中心、尺度或姿态估计。单位统一成米，保存明确方向的逆变换。

分别报告：

- 合成/伪参考指标：Chamfer定义、归一化及米制结果、逐SKU和宏平均、已知轴上的外缘尺寸误差。
- 真实指标：可信可见点到预测表面的残差、自由空间冲突、射线覆盖及叠加预览；无完整真值时不报告未经验证的背面精度。
- 独立性：训练样本、普通诊断、历史留出和新留出分别列出；训练样本上的改善不证明泛化。

射线指标记录前表面渲染/点投影方法、splat半径、稳定像素、容差和分母。覆盖低或没有命中时标为证据不足，不能以零冲突通过。点云投影和mesh射线、点到点和点到mesh不是同一口径。

用受控正确形状、已知位姿/深度偏移和无投影负例检查指标灵敏度。深度误差可能误拒正确几何；合成偏移实验不估计真实相机误差。隐藏面与内腔只能按证据标不确定。

先固定checkpoint选择与门槛，再训练；测试与真实留出在选择之后统一评价。看过结果后修改算法，应作为下一轮开发，不能继续宣称该测试未被接触。
