# Markdown 常用语法

常用 Markdown 与 Obsidian 语法速查。一般在标记符号后留一个空格；需要展示标记本身时，在符号前加反斜杠 `\`。

## 标题

```markdown
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
```

建议一篇笔记只使用一个一级标题，正文从二级标题开始分层。

## 文本样式

| 写法 | 效果 |
| --- | --- |
| `**粗体**` | **粗体** |
| `*斜体*` | *斜体* |
| `***粗斜体***` | ***粗斜体*** |
| `~~删除线~~` | ~~删除线~~ |
| `` `行内代码` `` | `行内代码` |
| `==高亮==` | ==高亮==（Obsidian 支持） |

## 段落、换行与分隔线

```markdown
这是第一段。

这是第二段。段落之间留一个空行。

行尾输入两个空格  
可以强制换行。

---
```

## 列表

### 无序列表

```markdown
- 第一项
- 第二项
  - 二级项目
  - 二级项目
```

`-`、`*`、`+` 都可以作为无序列表标记，建议统一使用 `-`。

### 有序列表

```markdown
1. 第一步
2. 第二步
   1. 子步骤
   2. 子步骤
```

### 任务列表

```markdown
- [ ] 待完成
- [x] 已完成
```

## 引用

```markdown
> 这是一段引用。
>
> > 这是嵌套引用。
```

## 链接与图片

### 标准 Markdown

```markdown
[链接文字](https://example.com)
[库内相对链接](../Home.md)
![图片说明](../_assets/example/image.png)
```

### Obsidian 内部链接

```markdown
[[Home]]
[[Home|返回首页]]
[[笔记名#章节标题]]
![[图片.png]]
![[笔记名#章节标题]]
```

- `[[笔记名]]`：链接到库内笔记。
- `![[文件名]]`：嵌入图片、PDF、音频或另一篇笔记。
- 正式笔记优先使用相对 Markdown 链接，离开 Obsidian 后仍可阅读。

## 代码

### 行内代码

```markdown
使用 `git status` 查看仓库状态。
```

### 代码块

````markdown
```python
print("Hello, Markdown!")
```
````

把 `python` 换成 `bash`、`javascript`、`json` 等语言名，可启用对应的语法高亮。

## 表格

```markdown
| 名称 | 用途 | 状态 |
| --- | :---: | ---: |
| Markdown | 写笔记 | 使用中 |
| Obsidian | 管理笔记 | 使用中 |
```

- `---`：默认左对齐。
- `:---:`：居中对齐。
- `---:`：右对齐。

## 转义特殊字符

在特殊字符前添加 `\`，可让它按普通文字显示。

```markdown
\# 这不是标题
\*这不是斜体\*
\[这不是链接\]
```

常见需要转义的字符：`\`、`` ` ``、`*`、`_`、`{}`、`[]`、`()`、`#`、`+`、`-`、`.`、`!`、`|`。

## Obsidian 常用扩展

### 提示块

```markdown
> [!note] 说明
> 这里填写补充信息。

> [!warning] 注意
> 这里填写风险或注意事项。

> [!tip] 建议
> 这里填写技巧。
```

### 脚注

```markdown
这句话需要补充说明。[^1]

[^1]: 这里填写脚注内容。
```

### 折叠内容

```markdown
<details>
<summary>点击展开</summary>

这里填写折叠内容。

</details>
```
